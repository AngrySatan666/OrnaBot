# OrnaBot

Automating Orna GPS RPG on Android Devices with ease!

**Note:** This is a port from my GoogleDrive of Scripts turned into *cough-cough* "Full-Stack" programming.

---

## History: 

OrnaBot was my first finished Project in coding, ever. 
After watching a Tik-Tok about Pythons pyautogui.locateOnScreen (),
I knew that it HAD to be possible to do this for Orna.
So I grabbed WordPad *yes... like an idiot" and with some research and dedication, 
built the first version of OrnaBot from wordpad on an HP Stream 12gb XD

I soon learned better coding methods and made version two which was controllable via a tktineter container,
and maxed out on kills/min at around 7.8 Avergae - 13.6 peak and was thirlled. 
Sooooo I let the bot run for two weeks nonstop and went from Global Rank #200,000+ to LeaderBoard Global Rank #81.
Aaaand decided to stop there.

Since then, the poor hp stream has been left behind by windows. To the point just the OS install takes up every single byte,
and you cant move files, make new files, nothing, Just see whats there. To being flashed with ArchCraft Linux and running better than it ever has.
so this repo is actually a redemption for the ol hp stream. I want to push the boundaries of all previous OrnaBot versions instilling more intelligence,
a much greater efficiency, gps augmentations, and the primary goal. To destory 7.8 - 13.6 kills/minute
